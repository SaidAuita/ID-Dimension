# Project Status

## Project
ID Dimension

## Path
C:\_CODE\indesign\ID Dimension

## Purpose
Инструмент для Adobe InDesign (CS6, CC 2014-2026+), предназначенный для автоматической простановки технических размеров, габаритных стрелок, выносок зазоров (Gap) между элементами макета, радиусов и диаметров. Поставляется одновременно в двух форматах: док-панель CEP и автономный скрипт ScriptUI.

## Current Version
1.4.1

## Current Development State
Стабильный релиз. Продукт функционально полон, протестирован на Windows и macOS.

## Current Task
Поддержка стабильности и совместимости с версиями InDesign 2026. Активная разработка новых крупных фич не ведется (Maintenance Mode).

## Completed Features
- **Два формата поставки**: современная CEP-панель и легковесный автономный .jsx скрипт для запуска через стандартную палитру скриптов InDesign без модификации реестра.
- **Габаритные размеры**: автоматическая простановка ширины и высоты фреймов, полос и векторных контуров.
- **Отключение стрелок (Arrow ON/OFF)**: чекбокс для быстрого включения/отключения стрелок на размерных линиях. Также стрелки автоматически отключаются при установке размера стрелки в 0 или пустом значении.
- **Измерение зазоров (Gap Measurement)**: измерение расстояния по 4 направлениям (горизонталь верх/низ, вертикаль лево/право) между объектами на развороте.
- **Радиусы и диаметры**: простановка радиуса (R) и диаметра (O) в 4 квадрантах с горизонтальными посадочными полками.
- **Поддержка масштаба чертежа (scale)**: поддержка архитектурных и выставочных масштабов (1:10, 1:50, 1:100, 2:1 и т.д.).
- **Поиск шрифтов (Searchable Font Picker)**: быстрый выбор шрифта прямо в панели с нечётким поиском и историей недавних шрифтов.
- **Единицы измерения**: мм, см, дюймы, пункты, пиксели.

## Known Problems
- В автономном ScriptUI варианте из-за ограничений встроенного диалогового окна InDesign окно открывается как плавающая палитра.

## Important Technical Decisions
- Двойная архитектура (CEP + ScriptUI) обеспечивает максимальную совместимость как для корпоративных пользователей со строгими политиками безопасности (где запрещен режим отладки CEP), так и для дизайнеров, предпочитающих интегрированные док-панели.
- Изоляция работы со слоями: все размерные линии группируются и при необходимости выносятся на отдельный технический слой.
