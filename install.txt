========================================================================
             ID DIMENSION PLUGIN INSTALLATION GUIDE
========================================================================
[Scroll down for Russian / Инструкция на русском языке ниже]

The tool supports Adobe InDesign versions CC 2014 – 2026+ on both Windows and macOS.

You can install either the Modern CEP Extension (dockable panel) or the Standalone Script (floating palette).

========================================================================
OPTION A: MODERN CEP EXTENSION (Dockable Panel)
========================================================================

--- WINDOWS ---
1. STEP 1: Enable Debug Mode
   Double-click `enable_player_debug_mode.reg` and confirm adding changes to the registry.

2. STEP 2: Copy Files
   Press Win + R, paste:
   %APPDATA%\Adobe\CEP\extensions
   and copy the entire `ID Dimension` folder there.

3. STEP 3: Launch
   Restart InDesign -> Window -> Extensions -> ID Dimension (or Extensions (Legacy)).

--- MACOS ---
1. STEP 1: Enable Debug Mode
   Open Terminal app and run this command:
   defaults write com.adobe.CSXS.9 PlayerDebugMode 1; defaults write com.adobe.CSXS.10 PlayerDebugMode 1; defaults write com.adobe.CSXS.11 PlayerDebugMode 1; defaults write com.adobe.CSXS.12 PlayerDebugMode 1; defaults write com.adobe.CSXS.13 PlayerDebugMode 1; defaults write com.adobe.CSXS.14 PlayerDebugMode 1; defaults write com.adobe.CSXS.15 PlayerDebugMode 1; defaults write com.adobe.CSXS.16 PlayerDebugMode 1

2. STEP 2: Copy Files
   In Finder, press Cmd + Shift + G, paste:
   ~/Library/Application Support/Adobe/CEP/extensions/
   (If the folder doesn't exist, create it) and copy the entire `ID Dimension` folder there.

3. STEP 3: Launch
   Restart InDesign -> Window -> Extensions -> ID Dimension (or Extensions (Legacy)).

========================================================================
OPTION B: STANDALONE SCRIPT (Floating Palette)
========================================================================
No debug mode or registry tweaks required.

--- WINDOWS ---
Copy `ID Dimension.jsx` into:
%APPDATA%\Adobe\InDesign\Version <XX.X>\<Locale>\Scripts\Scripts Panel\

--- MACOS ---
Copy `ID Dimension.jsx` into:
~/Library/Preferences/Adobe InDesign/Version <XX.X>/<Locale>/Scripts/Scripts Panel/

(Tip: In InDesign, open Window -> Utilities -> Scripts, right-click the "User" folder and choose "Reveal in Finder" / "Reveal in Explorer").

Launch by double-clicking `ID Dimension.jsx` in the InDesign Scripts panel.


========================================================================
           ИНСТРУКЦИЯ ПО УСТАНОВКЕ ПЛАГИНА ID DIMENSION
========================================================================

Поддерживаются версии Adobe InDesign CC 2014 – 2026+ на Windows и macOS.

Вы можете установить либо современное CEP-расширение (закрепляемая панель), либо отдельный скрипт (плавающая палитра).

========================================================================
ВАРИАНТ А: CEP-РАСШИРЕНИЕ (Закрепляемая панель)
========================================================================

--- WINDOWS ---
1. ШАГ 1: Включение режима отладки
   Запустите файл `enable_player_debug_mode.reg` двойным кликом и подтвердите добавление.

2. ШАГ 2: Копирование файлов
   Нажмите Win + R, вставьте:
   %APPDATA%\Adobe\CEP\extensions
   и скопируйте туда папку `ID Dimension`.

3. ШАГ 3: Запуск
   Перезапустите InDesign -> Окно -> Расширения -> ID Dimension (или Расширения (устаревшие)).

--- MACOS ---
1. ШАГ 1: Включение режима отладки
   Откройте программу "Терминал" (Terminal) и выполните команду:
   defaults write com.adobe.CSXS.9 PlayerDebugMode 1; defaults write com.adobe.CSXS.10 PlayerDebugMode 1; defaults write com.adobe.CSXS.11 PlayerDebugMode 1; defaults write com.adobe.CSXS.12 PlayerDebugMode 1; defaults write com.adobe.CSXS.13 PlayerDebugMode 1; defaults write com.adobe.CSXS.14 PlayerDebugMode 1; defaults write com.adobe.CSXS.15 PlayerDebugMode 1; defaults write com.adobe.CSXS.16 PlayerDebugMode 1

2. ШАГ 2: Копирование файлов
   В Finder нажмите Cmd + Shift + G, вставьте путь:
   ~/Library/Application Support/Adobe/CEP/extensions/
   (если папки нет — создайте её) и скопируйте туда папку `ID Dimension`.

3. ШАГ 3: Запуск
   Перезапустите InDesign -> Окно -> Расширения -> ID Dimension (или Расширения (устаревшие)).

========================================================================
ВАРИАНТ Б: ОТДЕЛЬНЫЙ СКРИПТ (Плавающая палитра)
========================================================================
Не требует включения режима отладки или правки реестра.

--- WINDOWS ---
Скопируйте `ID Dimension.jsx` в:
%APPDATA%\Adobe\InDesign\Version <XX.X>\<Locale>\Scripts\Scripts Panel\

--- MACOS ---
Скопируйте `ID Dimension.jsx` в:
~/Library/Preferences/Adobe InDesign/Version <XX.X>/<Locale>/Scripts/Scripts Panel/

(Совет: в InDesign откройте Окно -> Утилиты -> Сценарии, кликните правой кнопкой мыши по папке "Пользователь" и выберите "Показать в Finder" / "Показать в Проводнике").

Запуск: дважды кликните по `ID Dimension.jsx` в панели сценариев InDesign.
